# 브랜드 마스코트 (토끼 · 스위니)

아래 세 파일을 이 폴더에 넣으면 페이지 곳곳에 토끼가 나타납니다.
파일이 없으면 조용히 사라지므로, 일부만 넣어도 페이지는 정상 동작합니다.

| 파일명 | 그림 | 들어가는 곳 |
|---|---|---|
| `sweeny-run.png` | 선글라스 쓰고 포크 들고 달리는 토끼 | 첫 화면 균형 도넛 옆 |
| `sweeny-cheer.png` | 샐러드컵 번쩍 들고 환호하는 토끼 | "샐러드 업계 1위" 배너, 추천 결과 |
| `sweeny-salad.png` | 샐러드컵과 포크 들고 걷는 토끼 | 주간 기록 빈 화면, 푸터 |

## 권장 사양

- 배경 투명 PNG (흰 배경이면 카드 위에 흰 사각형이 보입니다)
- 세로 600px 이상
- 여백은 최소로 잘라주세요 — 페이지에서 높이 기준으로 배치합니다
