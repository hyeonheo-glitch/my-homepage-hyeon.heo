# 메뉴 사진

아래 네 개의 파일을 이 폴더에 넣으면 페이지의 이모지 접시가 자동으로 실제 사진으로 바뀝니다.
파일이 없으면 이모지 접시가 그대로 표시되므로, 일부만 넣어도 페이지는 정상 동작합니다.

| 파일명 | 메뉴 |
|---|---|
| `honey-ricotta.jpg` | 허니 리코타치즈 샐러드 |
| `cajun-chicken.jpg` | 케이준 치킨 샐러드 |
| `grilled-chicken.jpg` | 구운 고구마와 촉촉한 그릴드 닭가슴살 샐러드 |
| `mushroom-pumpkin.jpg` | 구운버섯 단호박 샐러드 |

## 권장 사양

- 정사각형에 가까운 비율 (접시 영역이 `object-fit: cover`로 채웁니다)
- 가로 800~1200px, 파일당 200KB 이하
- 상품명·설명 글자가 없는 **음식 사진만** — 페이지가 이름과 설명을 따로 표시합니다
