02 — Structure

화면 구성

위에서 아래로 네 개 섹션입니다. 세 번째가 이 페이지의 주인공입니다.

01
첫 화면 — 손님을 맞는 문장
헤드라인은 “오늘도 균형있게”, 아래 받침 문장은 “바쁜 하루에도, 운동 뒤에도.” 오른쪽은 이미지 없이 CSS conic-gradient로 그린 균형 도넛입니다 — 단백질 40% / 채소 30% / 곡물·좋은 지방 30%, 가운데에 420kcal. 아래에는 12분 · 34g · 새벽 4시 세 가지 사실을 배치했습니다.
02
대표 제품 소개
콥샐러드를 큰 카드로 세우고 닭가슴살 스테이크·그릴드 쉬림프 샐러드·로스트 치킨 그레인볼을 서브로 붙였습니다. 보이스 가이드의 ‘Specific over abstract’에 따라 형용사 대신 숫자를 먼저 씁니다 — 단백질 23g · 식이섬유 8g · 420kcal · 조리 3분. 영양 막대는 스크롤 진입 시 채워집니다.
03
점심 고민 해결 버튼 주인공
시간 · 컨디션 · 목표 세 가지를 고르고 버튼을 누르면 9개 메뉴 중 딱 하나를 추천합니다. 추천 이유를 3줄 근거로 함께 보여주고, 담은 메뉴는 아래 ‘이번 주 나의 균형 기록’에 쌓입니다. 자세한 동작은 다음 섹션에 정리했습니다.
04
하단 브랜드 소개
미션 문장(국문 + 영문), 브랜드 퍼스낼리티 Warm · Fresh · Honest 세 장, 그리고 슬로건 “Eat fresh, be your Best. / 진정으로 건강한 한 끼, 오늘도 균형있게.”로 마무리합니다.

03 — Hero Feature

점심 고민 해결 버튼은 이렇게 작동합니다

무작위 뽑기가 아닙니다. 세 가지 선택을 점수로 환산해 가장 잘 맞는 메뉴 하나를 고르고, 왜 골랐는지 근거를 함께 보여줍니다. 같은 답에는 같은 논리로 답합니다.

Step 1
세 가지를 고릅니다
시간(2) × 컨디션(5) × 목표(3) = 30가지 조합. 기본값이 미리 선택돼 있어 바로 눌러도 동작합니다.
Step 2
9개 메뉴를 채점합니다
조리시간·칼로리·단백질·식이섬유와 컨디션별 적합도를 더해 메뉴마다 점수를 냅니다.
Step 3
최고점 하나만 남깁니다
최근에 추천한 메뉴는 점수를 깎아, 같은 조합을 다시 눌러도 다른 메뉴가 나옵니다.
Step 4
근거와 함께 보여줍니다
점수를 올린 항목이 그대로 추천 이유 문장이 됩니다. 담으면 주간 기록에 누적됩니다.

실제 추천 결과 (브라우저에서 검증)

시간컨디션목표추천 결과보여주는 이유
10분 안에운동 후단백질닭가슴살 스테이크운동 뒤엔 이거예요. 단백질 32g, 280kcal.
여유 있게운동 후든든하게수비드 스테이크 샐러드운동 뒤엔 이거예요. 단백질 34g, 470kcal.
10분 안에운동 전가볍게단호박 리코타 샐러드이따 운동 가신다면 이 정도가 딱 좋아요. 350kcal.
10분 안에야근·늦은 끼니가볍게두부 유부 샐러드늦은 시간엔 가볍게. 330kcal로 부담을 줄였어요.
여유 있게속이 더부룩가볍게렌틸 채소 수프오늘은 속 편한 쪽으로. 식이섬유 10g 담았습니다.
여유 있게평범한 하루든든하게로스트 치킨 그레인볼오늘은 든든하게. 510kcal · 식이섬유 9g.

고객 건강에 어떻게 도움이 되나요

  • 고민 시간을 없앱니다. 메뉴판을 훑다 늘 먹던 걸 고르는 대신, 오늘 몸 상태에 맞는 한 끼가 바로 제시됩니다.
  • 선택의 근거를 배웁니다. “운동 직후엔 단백질을 빠르게”처럼 이유를 함께 읽으며 기준이 쌓입니다.
  • 습관이 눈에 보입니다. 주간 기록에 누적 단백질·채소 가짓수가 쌓여 다음 선택에 영향을 줍니다.

기록 기능 동작

  • ‘이 메뉴로 담기’를 누르면 담은 끼니 수 · 누적 단백질(g) · 누적 채소(종)가 갱신됩니다.
  • 브라우저 localStorage에 저장되어 새로고침해도 유지되고, ‘기록 지우기’로 초기화합니다.
  • 저장이 막힌 환경(시크릿 모드 등)에서도 try/catch로 감싸 페이지는 정상 동작합니다.
  • 대표 제품 카드의 담기 버튼도 같은 기록에 반영됩니다.

04 — Interview

반영된 나의 답변

인터뷰에서 답한 다섯 가지가 페이지 어디에 어떻게 들어갔는지 정리했습니다.

Q1. 이 홈페이지의 손님은?
바쁜 직장인 + 운동하는 사람
히어로 서브카피를 “점심시간은 짧고, 채워야 할 단백질은 그대로입니다”로 잡아 두 손님을 한 문장에 담았습니다. 추천 기능의 선택지도 이 두 사람을 위해 설계했습니다 — 시간축은 10분 안에, 컨디션축은 운동 전 / 운동 후가 5개 중 2개를 차지합니다.
Q2. 첫 화면에서 느꼈으면 하는 한 문장
오늘도 균형있게
히어로 H1에 브랜드 디스플레이 폰트(삼립호빵체)로 그대로 올렸습니다. 문장을 글자로만 두지 않고 균형 도넛 차트로 시각화해 ‘균형’을 눈으로 보이게 했고, 하단 슬로건 바에서 브랜드 원문으로 한 번 더 회수합니다.
Q3. 가장 보여주고 싶은 제품
콥샐러드
02 섹션의 주인공 카드로 크게 배치하고 NEW · 저당 배지와 ‘단골 재구매 1위’ 문구를 붙였습니다. 히어로 도넛이 보여주는 420kcal도 콥샐러드 기준이며, 추천 엔진에서도 평범한 하루의 기본값 역할을 합니다.
Q4. 나만의 아이디어 기능
점심 고민 해결 버튼
페이지의 주인공으로 만들었습니다. 매뉴얼의 ‘Primary CTA는 한 화면에 하나’ 규칙을 역이용해 페이지 전체에서 Vital Green Primary 버튼을 이 버튼 하나에만 썼습니다. 히어로 CTA조차 Secondary로 낮춰, 시선이 이 버튼으로 모이도록 설계했습니다.
Q5. 페이지의 분위기
신선한 초록 (Seed Green)
매뉴얼에 “한 화면에 Secondary 계열은 하나만”이라는 규칙이 있어, 답변과 규칙이 정확히 맞아떨어졌습니다. Soil Brown·Sky Blue를 페이지 전체에서 한 번도 쓰지 않고 Seed Green #84BA45 하나만 포인트로 사용했습니다 — 채소 막대, 담기 버튼, 추천 결과의 체크 표시, 제품 접시 그라데이션까지 전부 초록 계열로 통일했습니다.

05 — Compliance

디자인 시스템 준수 사항

매뉴얼의 규정을 그대로 따랐습니다. 답변과 충돌한 지점은 시스템을 우선했습니다.

✓페이지 배경은 Sunshine White, 순백은 카드·모달 표면에만 사용
✓Secondary 계열은 Seed Green 하나만 (Soil·Sky 미사용)
✓Primary CTA는 페이지 전체에 단 하나
✓8px 리듬 스페이싱, 컨테이너 1280px, 워크호스 radius 14px
✓모든 섀도우가 그린 틴트 — 회색 드롭섀도우 없음
✓모션 120 / 220 / 420ms, ease-out-soft · ease-spring
✓바운스 · 패럴랙스 · 지속 루프 애니메이션 없음
✓UI 아이콘은 Lucide 인라인 SVG (stroke 1.75, round cap)
✓로고는 지정 에셋 그대로 — 폰트로 재현하지 않음
✓마스코트 ‘냠’은 단색 실루엣 일러스트 앵커로만 사용
✓카피는 존댓말, 훈계 대신 응원, 스펙은 중점(·)으로 구분
✓숫자 표기 규칙 준수 — 23g / 420kcal / ₩9,900
충돌 처리 1 — 이모지. “색·도형·이모지로 표현해달라”는 요청과 매뉴얼의 “이모지를 UI 아이콘으로 사용 금지” 규정이 충돌했습니다. 매뉴얼을 우선해 버튼·내비게이션 아이콘은 Lucide 인라인 SVG로 그리고, 이모지는 매뉴얼 자체가 Product Card 예시에서 허용한 제품 이미지 자리와 선택 칩에만 사용했습니다. 외부 이미지 링크는 한 개도 쓰지 않았습니다.
충돌 처리 2 — 디자인 소스. 사내에 설치된 구버전 브랜드 가이드(배경 #FFFFFF, 포인트 Sunshine Yellow #F8CF77)와 첨부된 매뉴얼(Ver. 2025.07.25)이 달랐습니다. 최신 매뉴얼을 기준으로 삼았습니다.
남은 이슈 — 한글 본문 폰트. 매뉴얼 04장에 “한글 본문 폰트 미확정, Pretendard로 대체 중”이라는 경고가 그대로 남아 있습니다. 이 페이지도 동일하게 Pretendard를 쓰고 있으며, 확정되면 --kr 토큰 한 줄만 교체하면 됩니다.

06 — Technical

기술 메모

단일 파일

HTML · CSS · JS를 index.html 하나에 담았습니다. 빌드 도구나 의존성이 없어 파일을 열면 바로 동작합니다.

외부 이미지 0개

브랜드 로고와 마스코트는 매뉴얼 번들에서 꺼내 data URI로 내장했고, 나머지는 전부 CSS 도형과 이모지입니다.

폰트 내장 (228KB)

삼립호빵체·Chewy는 페이지에 실제 등장하는 462자만 서브셋했고, Montserrat는 가변폰트 원본을 넣었습니다.

접근성

  • 선택 칩은 aria-pressed로 상태를 노출합니다
  • 추천 결과 영역은 role="status" · aria-live="polite"
  • 장식용 이모지·마스코트는 aria-hidden 처리
  • 포커스 링은 브랜드 그린 2px (매뉴얼 규정)
  • prefers-reduced-motion에서 모든 전환을 끕니다

검증한 항목

  • 추천 엔진 30개 조합 중 6개 표본 — 전부 다른 결과 확인
  • 같은 조합 반복 — 최근 추천 회피 동작 확인
  • 기록 누적·초기화 동작 확인 (3끼 / 87g / 8종)
  • 1440px · 390px 렌더링, 가로 스크롤 0px
  • JS 런타임 오류 없음
